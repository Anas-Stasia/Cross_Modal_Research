# Reproducibility Checklist

## Data
- Obtain dataset from https://doi.org/10.34669/WI.RD/3 and review terms.
- Record retrieval date, dataset version, filenames, and SHA-256 hashes.
- Verify 5,136 unique video IDs align across metadata/text/audio/visual files.
- Verify embedding dimensions: text 512, audio 4,096, visual 2,304.
- Check and report missing and infinite values.
- Confirm metadata row count before deduplication (paper reports 11,242).
- Retain most recent scrape per video and report resulting row count.
- Validate engagement/follower values before `log(1 + x)`.
- Record exclusions and deviations.

## Splitting and preprocessing
- [ ] Record split code, random seed, and train/test video IDs.
- [ ] Verify 80/20 split and 1,028 test videos.
- [ ] Fit z-score statistics on training data only for alignment.
- [ ] Save preprocessing statistics and reuse on test data.
- [ ] Record category and indicator encoding for regression.

## Alignment model
- [ ] Use three two-layer projection heads with 128-dimensional outputs.
- [ ] Confirm InfoNCE objective across text–audio, text–video, audio–video.
- [ ] Record optimizer, learning rate, batch size, epochs, temperature, layer sizes, activations, regularization, and checkpoint rule.
- [ ] Record random seeds, software versions, and hardware.
- [ ] Save training logs and checkpoint.
- [ ] Evaluate random-weight retrieval baseline.



## Evaluation
- [ ] Evaluate held-out cross-modal top-1 retrieval with cosine similarity.
- [ ] Report retrieval results by modality pair and random baseline.
- [ ] Calculate MDS using the documented formula.
- [ ] Preserve individual pairwise similarities.
- [ ] Compute Spearman correlations for all four engagement metrics.
- [ ] Fit controlled OLS models using log followers, category, advertisement, and duet status.
- [ ] Report sample sizes, coefficients, p-values, and R².
- [ ] Recreate the PCA baseline and disclose that the paper fits PCA on the full sample.
- [ ] If fitting PCA on training data only, label it as an additional improved analysis.
- [ ] Compare results with README reference values and document discrepancies.

## Ethics and release
- [ ] Verify licensing, data access conditions, and institutional ethics requirements.
- [ ] Avoid publishing raw identifiers/data unless authorized.
- [ ] Keep claims associational, not causal.
- [ ] Discuss sample-selection and construct-validity limitations.
- [ ] Complete AI-use disclosure truthfully.
- [ ] Ensure figures/tables are generated by documented code.
- [ ] Archive code, configuration, logs, and environment specification.
- [ ] Attempt a clean-environment reproduction.
